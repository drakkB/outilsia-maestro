# OutilsIA Maestro

Native Rust application that makes your Ollama models and your Claude, Codex or Grok CLI sessions work as a team. Your project's tests decide the result, and a mission resumes after a failure without replaying what already passed. It reads no API key to call a provider.

- **Page and download:** https://outilsia.fr/maestro
- **Public version:** 0.7.1 public preview, Windows 11 (WSL for cloud sessions) and Linux. Free.
- **First mission:** https://outilsia.fr/maestro-premiere-mission

This repository holds release notes and checksums, without source code or binaries. Files are served by outilsia.fr; see [Releases](../../releases). Not related to Maestro by mobile.dev.
